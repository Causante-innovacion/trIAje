# ¿Cuál es la diferencia entre un plan de trabajo y una propuesta de proyecto?

## Respuesta

Aunque están relacionados, un **plan de trabajo** y una **propuesta de proyecto** tienen propósitos diferentes y se usan en momentos distintos. Aquí te explicamos las diferencias clave y cuándo usar cada uno.

---

## Definiciones

### Plan de Trabajo

**¿Qué es?**
Es un documento operativo que detalla **cómo ejecutarás** un proyecto ya aprobado. Es la guía interna para la implementación.

**Propósito**:
- Organizar actividades y responsabilidades del equipo
- Servir como herramienta de gestión y monitoreo interno
- Informar a donantes sobre el avance de un proyecto en ejecución

**Momento de uso**:
- **Después** de que el proyecto fue aprobado y financiado
- Durante la ejecución del proyecto
- Para reportar progreso a donantes

### Propuesta de Proyecto

**¿Qué es?**
Es un documento persuasivo que presentas a un **potencial donante** para solicitar financiamiento.

**Propósito**:
- Convencer al donante de que tu proyecto merece financiamiento
- Demostrar que tienes capacidad de ejecutarlo
- Describir qué cambios generarás con los fondos solicitados

**Momento de uso**:
- **Antes** de obtener financiamiento
- Durante procesos de postulación a fondos concursables
- En negociaciones con donantes

---

## Comparación Detallada

| Aspecto | Propuesta de Proyecto | Plan de Trabajo |
|---------|----------------------|-----------------|
| **¿Cuándo?** | Antes de obtener fondos (para solicitarlos) | Después de aprobar fondos (para ejecutar) |
| **Audiencia** | Donante externo (para convencerlo) | Equipo interno y donante (para guiar y reportar) |
| **Propósito** | Persuadir, obtener financiamiento | Operativizar, gestionar ejecución |
| **Tono** | Persuasivo, inspirador | Técnico, práctico |
| **Nivel de detalle** | General (qué se hará, por qué, impacto esperado) | Específico (quién hace qué, cuándo, cómo) |
| **Duración** | 3-15 páginas (según donante) | 5-30 páginas (según complejidad) |
| **Elementos clave** | Problema, solución, impacto, presupuesto, capacidad institucional | Cronograma detallado, responsables, indicadores, reportes |

## Contenido de una Propuesta de Proyecto

### Estructura Típica

#### 1. **Resumen Ejecutivo** (1 página)
- Qué problema abordas
- Solución propuesta
- Población beneficiaria
- Monto solicitado
- Impacto esperado

**Ejemplo**:
> "Este proyecto capacitará a 300 mujeres rurales de Ayacucho en educación financiera durante 12 meses, con un presupuesto de S/. 180,000. Se espera que el 70% aumente sus ingresos en 30%+ y el 50% acceda a microcréditos formales."

#### 2. **Diagnóstico del Problema**
- Situación actual (con datos estadísticos)
- Causas del problema
- Consecuencias si no se interviene
- Por qué tu organización está posicionada para resolverlo

#### 3. **Descripción del Proyecto**
- **Objetivo general**: El cambio que buscas lograr
- **Objetivos específicos**: Resultados intermedios (3-4)
- **Actividades principales**: Qué harás (sin entrar en microdetalle)

#### 4. **Metodología**
- Enfoque o modelo que usarás
- Por qué esta metodología es efectiva (evidencia, experiencia previa)

#### 5. **Población Beneficiaria**
- Número de beneficiarios directos e indirectos
- Criterios de selección
- Características demográficas

#### 6. **Cronograma General**
- Actividades por mes (tabla resumen)

| Actividad | M1 | M2 | M3 | M4 | M5 | M6 |
|-----------|----|----|----|----|----|----|
| Convocatoria | ✓ | | | | | |
| Talleres | | ✓ | ✓ | ✓ | | |
| Evaluación | | | | | ✓ | |
| Reporte final | | | | | | ✓ |

#### 7. **Presupuesto**
- Desglose por rubros (personal, actividades, equipos, administrativos)
- Justificación de costos principales

#### 8. **Resultados Esperados e Indicadores**
- Qué cambios medibles lograrás
- Indicadores de resultado (outputs y outcomes)

#### 9. **Sostenibilidad**
- ¿Cómo continuará el impacto después del proyecto?
- Capacidades que quedarán instaladas

#### 10. **Información Institucional**
- Misión, visión, experiencia
- Proyectos anteriores exitosos
- Equipo clave

> [!IMPORTANT]
> Adapta la propuesta a los requisitos específicos de cada donante. Siempre lee las bases o términos de referencia.

## Contenido de un Plan de Trabajo

### Estructura Típica

#### 1. **Introducción**
- Contexto del proyecto (ya aprobado)
- Objetivo general y específicos (ya definidos en propuesta)

#### 2. **Cronograma Detallado de Actividades**

Mucho más específico que en la propuesta:

| Actividad | Sub-actividad | Responsable | Sem 1 | Sem 2 | Sem 3 | Sem 4 | Entregable |
|-----------|---------------|-------------|-------|-------|-------|-------|------------|
| **Convocatoria** | | | | | | | |
| | Diseño de convocatoria | María | ✓ | | | | Documento convocatoria |
| | Difusión en redes | Juan | | ✓ | ✓ | | Posts Facebook/IG |
| | Recepción de postulaciones | María | | | ✓ | ✓ | Lista postulantes |
| | Selección | Comité | | | | ✓ | Lista seleccionados |
| **Taller 1** | | | | | | | |
| | Preparación materiales | Ana | ✓ | ✓ | | | Manuales impresos |
| | Ejecución taller | Luis | | | ✓ | | Taller ejecutado |
| | Evaluación post-taller | Ana | | | | ✓ | Informe evaluación |

#### 3. **Matriz de Responsabilidades**

| Rol | Persona | % Dedicación | Responsabilidades |
|-----|---------|--------------|-------------------|
| Coordinador General | María Pérez | 50% | Supervisión, relación con donante, reportes |
| Facilitador | Luis Torres | 30% | Ejecución talleres, evaluaciones |
| Asistente Logístico | Juan Díaz | 20% | Compras, coordinación logística |
| Contador | Ana Ramos | 10% | Gestión financiera, reportes contables |

#### 4. **Plan de Monitoreo**

| Indicador | Meta | Frecuencia Medición | Instrumento | Responsable |
|-----------|------|---------------------|-------------|-------------|
| N° participantes capacitados | 300 | Mensual | Lista de asistencia | Coordinador |
| % aprobación prueba final | 80% | Al final de cada taller | Prueba escrita | Facilitador |
| % satisfacción participantes | >90% | Al final de cada taller | Encuesta | Coordinador |

#### 5. **Plan de Comunicación y Reporte**

| Tipo de Reporte | Frecuencia | Destinatario | Responsable | Formato |
|-----------------|------------|--------------|-------------|---------|
| Reporte narrativo | Trimestral | Donante | Coordinador | Documento Word 10 pág |
| Reporte financiero | Trimestral | Donante | Contador | Excel + comprobantes |
| Reporte interno | Mensual | Junta Directiva | Coordinador | PPT resumen |

#### 6. **Presupuesto Ejecutado vs Planificado**

Se actualiza periódicamente durante ejecución:

| Rubro | Presupuestado | Ejecutado (Mes 3) | Saldo | % Ejecución |
|-------|---------------|-------------------|-------|-------------|
| Personal | S/. 60,000 | S/. 15,200 | S/. 44,800 | 25% |
| Actividades | S/. 40,000 | S/. 8,500 | S/. 31,500 | 21% |
| **TOTAL** | **S/. 100,000** | **S/. 23,700** | **S/. 76,300** | **24%** |

#### 7. **Gestión de Riesgos**

| Riesgo | Probabilidad | Impacto | Estrategia de Mitigación | Estado |
|--------|--------------|---------|--------------------------|--------|
| Retraso en desembolso | Media | Alto | Fondo de reserva creado | Mitigado |
| Baja asistencia a talleres | Alta | Medio | Incentivos (certificados, kits) | Monitoreando |

## Ejemplo Comparativo

### Propuesta de Proyecto (Lo que presentaste al donante)

**Actividad descrita**:
> "Se ejecutarán 10 talleres de educación financiera en comunidades rurales de Ayacucho, capacitando a 300 mujeres en temas de ahorro, presupuesto familiar y acceso a microcréditos."

**Cronograma**:
Mes 2-5: Ejecución de talleres

### Plan de Trabajo (Lo que usas para ejecutar)

**Actividad desglosada**:

**Taller 1: Introducción al ahorro**
- Semana 1: Diseño de contenido y materiales (Ana)
- Semana 2: Impresión de 30 manuales (Juan)
- Semana 3: Convocatoria y confirmaciones (María)
- Semana 4: Ejecución del taller (Luis) - Comunidad Chuschi
  - Día 1 (sábado 8am-1pm): Sesión teórica
  - Día 2 (domingo 8am-12pm): Ejercicios prácticos
- Semana 5: Pre y post-test, encuesta de satisfacción (Ana)
- Semana 5: Informe del taller al coordinador (Luis)

**Presupuesto detallado del Taller 1**:
- Facilitador: S/. 800 (2 días)
- Alquiler local: S/. 200
- Refrigerios: S/. 300 (30 personas x 2 días)
- Materiales: S/. 450 (30 manuales)
- Transporte equipo: S/. 150
- **Total Taller 1**: S/. 1,900

## ¿Cuándo Usar Cada Uno?

### Usa una Propuesta de Proyecto cuando:

- ✅ Buscas financiamiento de un donante
- ✅ Participas en un concurso de fondos
- ✅ Presentas una idea nueva a tu junta directiva
- ✅ Buscas alianzas (la propuesta demuestra tu visión)

### Usa un Plan de Trabajo cuando:

- ✅ Ya obtuviste financiamiento y necesitas ejecutar
- ✅ El donante solicita plan de implementación detallado
- ✅ Presentas avances en reportes trimestrales/semestrales
- ✅ Necesitas organizar internamente al equipo

---

## Relación Entre Ambos

```
Propuesta de Proyecto (General)
         ↓
    [Aprobación + Financiamiento]
         ↓
  Plan de Trabajo (Detallado)
         ↓
    [Ejecución del Proyecto]
         ↓
  Reportes de Avance (basados en Plan de Trabajo)
```

> [!TIP]
> Empieza con una buena propuesta para obtener fondos. Luego, tradúcela en un plan de trabajo realista para ejecutar con éxito.

## Errores Comunes

### En Propuestas

❌ **Demasiado detalle operativo**: "En la semana 3, Juan comprará 50 lapiceros en la librería X"
✅ **Nivel adecuado**: "Se adquirirán materiales didácticos para los talleres"

❌ **Presupuesto sin justificación**: Una laptop de S/. 5,000 sin explicar su uso
✅ **Justificación clara**: "Laptop para coordinador de M&E, uso exclusivo en ingreso de datos y análisis estadístico"

### En Planes de Trabajo

❌ **Demasiado vago**: "Hacer talleres en el mes 2"
✅ **Específico**: "Taller 1: 15 de febrero en Chuschi, Taller 2: 22 de febrero en Huambalpa"

❌ **Sin responsables**: "Se ejecutará taller"
✅ **Con responsable**: "Luis ejecuta taller, Ana prepara materiales, María coordina logística"

## Preguntas Frecuentes

**¿Debo incluir plan de trabajo en la propuesta?**
Depende del donante. Algunos piden cronograma básico en propuesta y luego plan detallado si apruebas. Lee las bases.

**¿Puedo ajustar el plan de trabajo si algo no funciona?**
Sí, es flexible. Comunica cambios al donante si son significativos. Ajustes menores son normales.

**¿El plan de trabajo es solo para el donante?**
No, es principalmente para ti (gestión interna). Luego usas versiones resumidas para reportar al donante.

**¿Cada cuánto actualizo el plan de trabajo?**
Mensual o trimestral, según la dinámica del proyecto.
