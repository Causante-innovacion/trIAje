# ¿Qué elementos debe tener un plan de trabajo y un presupuesto para presentar a un donante?

## Respuesta

Un plan de trabajo y presupuesto bien estructurado demuestra profesionalismo, claridad de objetivos y capacidad de gestión. Estos son los elementos esenciales:

### Elementos del Plan de Trabajo

#### 1. **Resumen Ejecutivo** (1 página máximo)

- Nombre del proyecto
- Descripción breve del problema que se busca resolver
- Objetivo general
- Población beneficiaria
- Duración del proyecto
- Monto solicitado

#### 2. **Diagnóstico o Análisis de Situación**

- **Problema identificado**: ¿Qué situación quieren cambiar?
- **Causas y consecuencias**: Análisis del contexto
- **Población afectada**: Datos cuantitativos y cualitativos
- **Justificación**: ¿Por qué es necesario este proyecto?

> [!TIP]
> Usa datos estadísticos concretos de fuentes oficiales (INEI, ministerios) para respaldar tu diagnóstico.

#### 3. **Objetivo General y Objetivos Específicos**

- **Objetivo General**: El cambio de largo plazo que se busca lograr
- **Objetivos Específicos**: Resultados intermedios medibles (máximo 3-4)

**Criterios SMART**:
- **S**pecífico (claro y concreto)
- **M**edible (cuantificable)
- **A**lcanzable (realista)
- **R**elevante (alineado con misión institucional)
- **T**emporal (con plazo definido)

**Ejemplo**:
✅ BIEN: "Capacitar a 100 mujeres rurales en gestión empresarial durante 6 meses"
❌ MAL: "Apoyar a mujeres"

#### 4. **Resultados Esperados (Productos o Entregables)**

- Qué se va a producir concretamente
- Indicadores de resultado

**Ejemplo**:
- 100 personas capacitadas
- 3 talleres ejecutados
- 1 manual de buenas prácticas publicado

#### 5. **Actividades y Cronograma**

Usa una tabla con las siguientes columnas:

| Actividad | Responsable | Mes 1 | Mes 2 | Mes 3 | Mes 4 | Mes 5 | Mes 6 |
|-----------|-------------|-------|-------|-------|-------|-------|-------|
| Convocatoria de participantes | Coordinador | ✓ | | | | | |
| Taller 1: Gestión financiera | Facilitador | | ✓ | | | | |
| Taller 2: Marketing | Facilitador | | | ✓ | | | |
| Evaluación de aprendizaje | M&E | | | | ✓ | | |
| Reporte final | Coordinador | | | | | | ✓ |

> [!IMPORTANT]
> El cronograma debe ser realista. Considera tiempos de convocatoria, desplazamientos y posibles retrasos.

#### 6. **Equipo de Trabajo**

- Nombres y roles de las personas involucradas
- Perfiles profesionales y experiencia relevante
- % de dedicación al proyecto

**Ejemplo**:
- María Pérez - Coordinadora General (50% dedicación) - Educadora con 5 años de experiencia en zona rural
- Juan Torres - Facilitador (30% dedicación) - Contador público colegiado

#### 7. **Sostenibilidad del Proyecto**

- ¿Cómo continuará el proyecto después de que termine el financiamiento?
- ¿Qué capacidades quedarán instaladas?
- ¿Hay aliados estratégicos comprometidos?

#### 2. **Categorías de Gastos Comunes**

**Gastos Directos**:
- Personal del proyecto
- Actividades con beneficiarios
- Materiales y equipos específicos
- Transporte directo

**Gastos Indirectos (Administrativos)**:
- Servicios básicos (luz, agua, internet)
- Alquiler de oficina
- Personal administrativo compartido
- Seguros

> [!IMPORTANT]
> Muchos donantes limitan gastos administrativos a 10-15% del total. Verifica las políticas del financiador.

#### 3. **Contrapartida**

Algunos donantes exigen contrapartida:

| Concepto | Aporte Donante | Contrapartida Organización | Total |
|----------|----------------|----------------------------|-------|
| Personal | S/. 24,000 | S/. 6,000 (Director) | S/. 30,000 |

Contrapartida puede ser:
- **Monetaria**: Aportes en efectivo de la organización
- **No monetaria**: Uso de oficina, equipos, voluntarios, tiempo del personal

## Consideraciones Clave

### 1. **Alineación con el Donante**

Antes de elaborar el plan:
- ✅ Lee cuidadosamente las **bases del concurso** o términos de referencia
- ✅ Identifica **prioridades temáticas** del donante
- ✅ Verifica **montos máximos/mínimos** de financiamiento
- ✅ Conoce **rubros elegibles** (qué se puede financiar y qué no)
- ✅ Confirma **plazos de ejecución** aceptables

### 2. **Errores Comunes a Evitar**

❌ **Presupuestos inflados o poco realistas** (ej: S/. 10,000 por un taller de 3 horas)
❌ **Actividades sin cronograma** o fechas vagas
❌ **Objetivos demasiado ambiciosos** para el tiempo/presupuesto
❌ **No incluir indicadores verificables**
❌ **Gastos no justificados** (ej: pedir laptop sin explicar su uso específico)

### 3. **Respaldo de Costos**

Algunos donantes piden cotizaciones:
- Guarda 3 cotizaciones de proveedores para equipos mayores
- Usa tarifas del mercado verificables (ej: tarifas profesionales de colegios)
- Para materiales fungibles, usa precios promedio razonables

## Preguntas Frecuentes

**¿Puedo incluir salarios en el presupuesto?**
Sí, pero algunos donantes limitan el % destinado a personal. Verifica las políticas específicas.

**¿Qué pasa si necesito ajustar el presupuesto durante la ejecución?**
La mayoría de donantes permite ajustes menores (±10% entre rubros). Cambios mayores requieren aprobación previa escrita.

**¿Es obligatorio tener RUC para recibir fondos?**
Sí, para fondos formales (donaciones de empresas, cooperación internacional, fondos concursables). El donante necesita emitir comprobantes fiscales.

**¿Puedo presentar el mismo proyecto a varios donantes?**
Sí, pero debes informar si recibes financiamiento múltiple para evitar duplicidad de gastos.
